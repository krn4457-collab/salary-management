# Demo

1. `cd backend && pip install -r requirements.txt && python scripts/seed.py && uvicorn app.main:app --reload`
2. `cd frontend && npm install && npm run dev`
3. Open http://localhost:5173 → dashboard KPIs, filter table, click Edit to update a salary, Delete to remove a record.
4. API docs: http://localhost:8000/docs

Video: record 2-min walkthrough (dashboard → search "Sharma" → filter India → edit salary → stats update).
